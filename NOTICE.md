# Source and asset scope

The initial snapshot was extracted from CrossCourt's owner-authored Sabbo client
with a fresh history. It includes the Swift implementation, native tests, privacy
metadata and dependency-free Xcode generator. Deployment-specific values were
moved into a separate profile; the public defaults contain synthetic identities.

All bundled learning exercises here are original examples written for this
repository. All bundled PNGs are newly generated geometric placeholders, with
no third-party source images or metadata. Existing production curriculum,
photographs, avatars, reward messages, illustrations and animated media were
excluded. No private Git history, release logs, user answers, backend source,
operator documentation or platform manifests were copied.

The MIT license covers the files included here. It does not grant rights to
excluded production assets, a hosted service, or Apple platform software.
Apple frameworks and system symbols are provided by the operating system.
